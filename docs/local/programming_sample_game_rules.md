## 프로그래밍 샘플

### 목표
- 안드로이드 스튜디오에서의 프로그래밍 방식을 제안하기 위한 예제 프로그램을 작성한다.
- 아주 간단한 게임; 버튼을 누르면 랜덤으로 점수가 변하는 게임

### 화면 구성
1. 메인 메뉴
2. 게임 화면
3. 게임 결과 화면

### 각 화면별 구성 요소

#### 메인 메뉴
|요소|설명|
|---|---|
|게임 시작 버튼|게임 화면으로 넘어간다.|
|게임 종료 버튼|앱을 종료한다.|
|게임 기록 버튼|최근 5게임의 점수와 역대 최고 점수를 보여준다.|

#### 게임 화면
|요소|설명|
|---|---|
|점수 up 버튼|1점에서 10점 사이 랜덤하게 점수가 오른다. (정수)|
|점수 down 버튼|1점에서 10점 사이 랜덤하게 점수가 감소한다. (정수)|
|점수 확정 버튼|결과 화면으로 이동한다.|
|뒤로 가기 버튼|메인 메뉴로 이동한다.|
|현재 점수 표시|현재 점수를 표시한다.|
|최고 점수 표시|최고 점수를 표시한다.|

#### 게임 결과 화면
|요소|설명|
|---|---|
|최종 점수 표시|이번 게임의 결과 점수를 표시한다.|
|최고 점수 표시|최고 점수를 표시한다.|
|메인 메뉴 버튼|메인 메뉴로 이동한다.|
|다시 시작 버튼|게임 화면으로 이동하여 게임을 처음부터 다시 시작한다.|
